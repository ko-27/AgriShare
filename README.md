## 📋 Course Outcomes & Experiment Objectives
- **Style Sheets Architecture:** Complete demonstration of **External Style Sheet** (`style.css`), **Internal Style Sheet** (`<style>` in `<head>`), and **Inline Styles** (`style="..."`).
- **CSS3 Layout Systems:** Responsive layouts engineered with CSS Grid and Flexbox with media queries across breakpoints (1200px, 992px, 768px).
- **CSS Custom Properties & Theming:** `:root` variables supporting real-time Light/Dark mode transitions with `localStorage` persistence.
- **Advanced Selectors & Pseudo-Elements:** Demonstration of `::before`, `::after`, `::first-letter`, `::first-line`, and `::selection`.
- **CSS3 Transformations & Animations:** Hardware-accelerated `translate()`, `rotate()`, `scale()`, and `skew()` effects with CSS transitions and animated striped progress bars.
- **CSS-Only Tooltips & Image Effects:** Pure CSS tooltips on action buttons and zoom/grayscale/brightness/overlay effects on cards.
