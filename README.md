## 📋 Course Outcomes & Experiment Objectives
- **Design Structured Web Pages:** Structured layout using semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
- **HTML5 Drag and Drop APIs:** Interactive machinery scheduler using native `dragstart`, `dragover`, `drop`, and `dragleave` events.
- **Client-Side Web Storage (localStorage):** Persistent storage of all registered farmer and machinery reservation records across sessions.
- **Client-Side Web Storage (sessionStorage):** Tab-isolated session storage capturing active farmer details and scheduled rental equipment.
- **Dynamic Retrieval & Deletion:** Real-time data retrieval with tabular display and complete storage clearance with confirmation alert.
